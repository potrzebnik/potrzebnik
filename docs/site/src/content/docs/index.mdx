## Prerequisites

Install these before touching the repo:

- Node.js, at the version pinned in <RepoFile path=".nvmrc" />
- [pnpm](https://pnpm.io/installation)
- Docker with Docker Compose

## Clone and install

```bash
git clone https://github.com/potrzebnik/potrzebnik.git
cd potrzebnik
pnpm install
```

Installing dependencies also wires up the git hooks described on the
Contributing page.

## Configure environment variables

Copy the example environment file:

```bash
cp .env.example .env
```

The defaults work without Google OAuth keys — local development runs with
`GOOGLE_AUTH_ENABLED=false`. To exercise Google sign-in locally, set
`GOOGLE_AUTH_ENABLED=true` along with `GOOGLE_CLIENT_ID` and
`GOOGLE_CLIENT_SECRET` in `.env`, and register the local redirect URI in
Google Cloud. See the Auth & OAuth page for the full flow.

## Start the database and dev server

```bash
bash startup_dev.sh
```

This brings up the local Postgres instance defined in <RepoFile path="compose.yml" /> and starts
the Next.js dev server.

Once the database is running, apply migrations as described on the Database
page.

## Run Storybook

Storybook is the primary component test harness. Start it locally with:

```bash
pnpm storybook:dev
```

See the Testing page for how stories fit into the wider test suite.

## Read these docs locally

This site and the component gallery build and serve together with one
command:

```bash
pnpm docs
```

It serves at `http://localhost:4321/potrzebnik/` — the same subpath the site
is published under. The Contributing page covers editing pages with live
reload.
