title: Agent & skill index
description: Every agent, command, and skill defined in .claude/.
---

import agentsIndex from '../../../generated/agents-index.json';

`.claude/` stays the canonical source for every agent, command, and skill definition. This index
is regenerated on every docs build straight from that directory's frontmatter, so it cannot drift
out of date the way a hand-maintained list would. Full agent bodies are deliberately not
republished here — open the linked file for the actual system prompt or skill steps.

## Agents

{agentsIndex.agents.length === 0 ? (
  <p>No agents are defined under <code>.claude/agents</code> right now.</p>
) : (
  <table>
    <thead>
      <tr>
        <th>Name</th>
        <th>Description</th>
        <th>Definition</th>
      </tr>
    </thead>
    <tbody>
      {agentsIndex.agents.map((entry) => (
        <tr>
          <td>{entry.name}</td>
          <td>{entry.description}</td>
          <td>
            <a href={`https://github.com/potrzebnik/potrzebnik/blob/main/${entry.path}`}>
              {entry.path}
            </a>
          </td>
        </tr>
      ))}
    </tbody>
  </table>
)}
