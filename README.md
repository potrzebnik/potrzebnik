# Potrzebnik

Potrzebnik connects people who want to help with the organizations that need it — a public
Next.js application listing charities, shelters, and the concrete things they are short of.

Everything a contributor needs to run, change, and ship this project lives on the
**[contributor documentation site](https://potrzebnik.github.io/potrzebnik/)**.
